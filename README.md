# 🎨 Generador de Infografías IA

Aplicación web interactiva para crear infografías, mapas mentales, flashcards, pósters científicos y otros recursos visuales educativos utilizando inteligencia artificial.

Diseñada para docentes, estudiantes, creadores de contenido y diseñadores educativos que desean generar materiales visuales modernos de manera rápida e intuitiva.

---

## ✨ Características principales

- 🧠 Generación automática de recursos visuales con IA
- 📊 Creación de infografías educativas
- 🗺️ Generación de mapas mentales
- 🃏 Flashcards de estudio
- 🧪 Pósters científicos
- 📚 Cuentos infantiles ilustrados
- 🏅 Diplomas escolares
- 📌 Cheat Sheets
- 💬 Cómics educativos
- 🖼️ Vista previa en tiempo real
- 🧩 Sistema de plantillas dinámicas
- ✍️ Editor de *system prompts*
- 🔑 Gestión integrada de API Key
- 🌍 Cambio rápido entre español e inglés
- 📐 Selección de formatos y relaciones de aspecto
- 📥 Descarga directa de imágenes generadas

## 🚀 Cómo usar

1. Clona este repositorio:

```bash id="iwf1v6"
git clone https://github.com/tuusuario/tu-repositorio.git
```

2. Abre el archivo:

```bash id="3oowmv"
index.html
```

3. Ingresa tu API Key.

4. Selecciona el tipo de recurso visual.

5. Escoge una plantilla.

6. Personaliza el *system prompt* si lo deseas.

7. Haz clic en **Generar imagen**.
